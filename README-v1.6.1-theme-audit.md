# Media Library v1.6.1 — theme parity and layout audit

Патч накладывается поверх проекта Media Library v1.6. Внутри только изменённые файлы.

## Что исправлено

- `gallery-toolbar` получил стабильную адаптивную раскладку; фильтр категории больше не выходит из обёртки из-за конфликта ширины 126 px у wrapper и `min-width: 148px` у select.
- `field-control gallery-category-filter`: улучшены фон, цвет текста, состояние фокуса, стрелка, а также правила для `option`, `optgroup` и выбранного пункта в тёмной и светлой темах.
- Активная навигация `router-link-active`, `router-link-exact-active`, `nav-link.is-active` получает контрастный текст и видимое выделение в светлой теме.
- Добавлена общая theme-parity-поддержка для импорт-страницы, очереди/прогресса/журнала, `app-global-status`, `app-status-item`, уведомлений `.notice` и `.app-alert`, архива, базы файлов, настроек, дерева папок, библиотеки обоев и просмотрщиков фото/видео.
- Liquid Glass теперь охватывает соответствующие панели импорта, статуса, уведомлений, настроек, архивов и контролов, а Standard сохраняет непрозрачные поверхности без размытия.
- Video.js получает светлую панель контролов, читаемые значки/таймеры и акцентные индикаторы прогресса; сами пиксели видео остаются нейтральными.
- Светлая тема использует тёмный читаемый текст для подписей, включая `.field-label` (вместо прежнего фиксированного `#c0c4cb`), и контрастные состояния предупреждений/успеха/ошибок.
- Если выбран стандартный фон приложения `#101114` и тема переключена на светлую, визуальный фон становится светлым (`#f2f5f9`). Пользовательский цвет фона не переписывается и продолжает использоваться как заданный.

## Проверки

- `tinycss2`: 1054 правила CSS, ошибок разбора не найдено.
- Проверено наличие theme-правил для `gallery-toolbar`, category select/options, активного RouterLink, import page, status items, warning notices, Video.js и фона обоев.
- TypeScript проверен с глобальным `tsc`; синтаксических ошибок в изменённой функции нет, но полная проверка типов невозможна без установленных проектных зависимостей (`vue`, `@tauri-apps/api` и остального проекта).
- Полную сборку Vue/Tauri и визуальную проверку на Windows в текущем окружении выполнить не удалось.
