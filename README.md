# Локальная медиатека — MVP-каркас

Стартовый каркас локального приложения для Windows 10/11 x64: Vue 3, TypeScript, Tailwind CSS 4, Vite, Tauri 2 и подготовленные зависимости для SQLite и системных диалогов.

> Это ранний MVP: навигация, папка медиатеки, импорт фото/видео и базовые просмотрщики уже предусмотрены. Список галерей пока читается сканированием файловой системы, а не из SQLite. Полную сборку Tauri следует проверить на Windows после установки зависимостей.

## Что входит

- Главная со ссылками на разделы.
- Галерея видео с сеткой 2–6 колонок, импортом, встроенным просмотрщиком и регулировкой громкости.
- Галерея фото с сеткой 2–6 колонок, импортом, просмотрщиком и масштабированием колёсиком.
- Страница настроек для создания корневого каталога медиатеки и структуры IRL / Аниме / 3D с подкаталогами Фото / Видео / Архивы.
- Галерея архивов.
- База данных файлов с примерными полями, поиском и фильтром по типу.
- Vue Router, TypeScript, Tailwind CSS 4 и Vite.
- Tauri 2: окно Windows и NSIS-установщик `.exe`.
- Подключены плагины Tauri для системных диалогов, базовых операций файловой системы, открытия внешних приложений и SQLite.
- Черновая схема будущей SQLite-базы в `database/schema.sql`.
- Примерные папки для компонентов, сервисов, состояния, миграций, команд Rust и тестов.
- CMD-скрипты для установки, браузерного превью, запуска настольной версии, проверки и сборки.

## Быстрый старт в Windows

### 1. Подготовить окружение

Для браузерного превью нужен Node.js LTS с npm. Для настольной версии и `.exe` дополнительно установите системные prerequisites Tauri для Windows: Rust (MSVC toolchain), Microsoft C++ Build Tools и WebView2 Runtime.

Инструкция Tauri: <https://v2.tauri.app/start/prerequisites/>

### 2. Установить npm-модули

Дважды щёлкните `install.cmd`. Скрипт выполнит `npm install`, а если Cargo уже доступен, попробует скачать Rust-зависимости.

### 3. Открыть проект в браузере

Дважды щёлкните `run-web.cmd`. Vite запустится на `http://127.0.0.1:1420` и откроет страницу в браузере. Это удобно для работы над интерфейсом, но браузерный режим не получает прямой доступ к произвольным путям дисков Windows.

### 4. Запустить как Windows-приложение

Дважды щёлкните `run-desktop.cmd`. Откроется окно Tauri. При первом запуске Rust может скачать зависимости и скомпилировать нативную часть.

### 5. Собрать установщик

Запустите `build-windows.cmd`. При успешной сборке установщик NSIS `.exe` обычно появится в `src-tauri/target/release/bundle/nsis/`.

`check.cmd` запускает проверку типов и сборку фронтенда.

## Архитектурные правила для следующих этапов

1. **Не хранить коллекцию внутри каталога установки.** Пользователь выберет отдельный корень медиатеки, например `D:\MediaLibrary`. Установщик и обновления не должны касаться этого каталога.
2. **Хранить в SQLite относительные пути внутри медиатеки.** Так перенос корневой папки на другой диск не потребует переписывать каждый путь в базе.
3. **Разделить UI и операции с файлами.** Vue-компоненты вызывают сервис; системные операции Windows делаются через ограниченные команды Rust или разрешённые Tauri API.
4. **Не делать перемещение опасной операцией «в один шаг».** Между дисками безопаснее реализовать копирование → проверку результата → обновление БД → удаление источника только после подтверждения. При ошибке исходник должен оставаться на месте.
5. **Явно запрашивать выбор корня медиатеки.** Не давать приложению неограниченный доступ ко всем дискам просто ради удобства. Разрешения и подтверждения должны соответствовать конкретной операции.
6. **Метаданные Windows не одинаковы у всех файлов.** Сохранять общие сведения в колонках, дополнительные сведения конкретных форматов — в `metadata_json` или нормализованных таблицах.
7. **Обновления включать после настройки релизов.** Для механизма автообновления понадобятся канал публикации, URL обновлений и подпись/публичный ключ. В этом каркасе обновление не настроено.

## Что пока намеренно не сделано

- реальная SQLite-база и миграции при запуске;
- постоянная индексация списка файлов в SQLite; сейчас галереи сканируют известные папки при открытии или обновлении;
- пакетная обработка и очередь сортировщика;
- чтение EXIF/Windows metadata и извлечение характеристик видео;
- генерация миниатюр и расширенная обработка метаданных;
- создание и редактирование тегов;
- очередь сортировщика новых файлов;
- автоматическая проверка и установка обновлений;
- тесты.

Это отдельные следующие этапы, чтобы сначала получить понятный и запускаемый фундамент без лишнего кода.


## Текущий этап: галереи и файловое хранилище

- В Desktop-режиме страница настроек создаёт `IRL/Фото`, `IRL/Видео`, `IRL/Архивы`, а также эквивалентные каталоги в `Аниме/` и `3D/`.
- Импорт фото и видео поддерживает копирование или безопасное перемещение (копирование → проверка размера → удаление исходника). При конфликте имён создаётся новое имя, существующий файл не перезаписывается.
- Галереи сканируют выбранную структуру файловой системы при открытии/обновлении; SQLite пока не является источником списка.
- В браузерном режиме файлы можно выбрать или перетащить для временного предпросмотра, но они не сохраняются на диск.
- Автор пока не редактируется в UI. В схеме тегов добавлен `tag_type` со значениями `general` / `creator`, чтобы позже создать страницу авторов без изменения модели связей медиа–тег.
- Доступ к превью-ресурсам Tauri динамически ограничивается выбранной папкой медиатеки, а не всем файловым диском.
