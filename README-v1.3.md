# Media Library v1.3 — Concept 01: Quiet Graphite

Этот патч меняет визуальное направление приложения, не заменяя логику галерей, импорта, просмотрщиков и конфигурации. Это тестовый дизайн-концепт для выбора направления, а не обязательное финальное оформление.

## Идея
- Roboto вместо Oswald — более привычная и читаемая типографика.
- Спокойная графитовая палитра; акцентный цвет берётся из текущих настроек пользователя. Для новых конфигов используется холодный синий оттенок. Существующий пользовательский цвет не перезаписывается.
- Убраны избыточные градиенты, светящиеся рамки, декоративная иллюстрация на главной и дублирующие подписи в оболочке.
- Более компактные навигация, верхняя панель, карточки и просмотрщики; крупнее читаемый текст и более спокойные состояния наведения.
- Сохранены существующие классы компонентов, чтобы патч не ломал поведение страниц.

## Установка
Применить поверх проекта v1.2 с заменой файлов по сохранённым путям. Новые зависимости не добавляются.

Шрифт Roboto загружается из Google Fonts при наличии сети; при её отсутствии используется Segoe UI / Arial. Полную сборку Vue/Tauri необходимо проверить в проектном окружении.
