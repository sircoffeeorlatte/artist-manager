# Media Library v1.7 — Runtime SQLite index

Этот патч добавляет настоящую SQLite-базу в настольную версию Tauri и переводит фото-, видео- и архивные галереи на чтение из индекса.

## Применение

Распакуйте архив поверх проекта **v1.6.3**, сохранив каталоги и заменив указанные файлы. Патч содержит только изменённые и добавленные файлы, а не полный проект.

При первом запуске настольной версии миграция создаст `media-library.sqlite3` в папке данных приложения. При первом обращении к выбранной медиатеке приложение выполнит первичную индексацию. Следующие открытия галерей выполняют SQL-запрос вместо полного обхода папок. Новые успешные импорты обновляют индекс. Для проверки внешних изменений на диске используй кнопку **«Переиндексировать»** на странице «База файлов».

В «Базе файлов» доступны статус индекса, путь к DB, количество доступных/отсутствующих файлов, даты индексации и редактирование общих тегов.

## Проверки

В этом окружении прошли 4 SQL smoke-теста, синтаксическая проверка TypeScript-частей, разбор JSON/TOML конфигураций и проверка миграции. Полная сборка Vue/Tauri не запускалась: npm-зависимости не установились по тайм-ауту, Rust/Cargo в окружении отсутствуют. Перед использованием на Windows выполни `install.cmd`, `check.cmd` и `cargo check --manifest-path src-tauri/Cargo.toml`.
