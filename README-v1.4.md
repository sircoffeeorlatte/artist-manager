# Media Library v1.4 — Player, TikTok and background settings

Патч предназначен для применения поверх Media Library v1.3 (Quiet Graphite). Он содержит только изменённые исходники, без полной копии проекта и без новых npm-зависимостей.

## Изменения

- Скрыты `page-eyebrow` подписи в интерфейсе.
- Явно восстановлен иконный шрифт Video.js, чтобы кнопки стандартного плеера не оставались без значков.
- TikTok-режим использует тот же компонент `LibraryVideoPlayer.vue`, что и обычный просмотрщик: штатные play/pause, звук, громкость, скорость и полноэкранный режим.
- Кнопки переключения соседних видео и открытия обычного просмотрщика вынесены в боковую колонку справа от видеокадра, а не поверх него.
- Выпадающие списки категорий и настроек получили тёмную палитру, стрелку и состояния выбора в стиле приложения.
- Дерево папок в настройках заменено на компактную структуру категорий с иконками и подпапками.
- Добавлен выбор пользовательского цвета фона приложения с готовыми тёмными пресетами. Выбор сохраняется в `user-config.json` как `appearance.backgroundColor`.
- Обновлена Rust-модель `AppearanceConfig`: старые конфиги без `backgroundColor` продолжают читаться и получают безопасный цвет по умолчанию.

## Установка

1. Распакуйте ZIP поверх проекта v1.3 с сохранением структуры каталогов.
2. Замените файлы по их исходным путям.
3. Перезапустите dev-сервер или пересоберите настольную версию Tauri.

## Проверки

Проверены синтаксис TypeScript-частей Vue-компонентов, баланс шаблонных HTML-тегов, разбор CSS и целостность ZIP. Полная сборка Vue/Tauri и Rust здесь не запускалась, поэтому после применения необходимо проверить сборку в Windows-окружении и протестировать полноэкранный режим Video.js.
