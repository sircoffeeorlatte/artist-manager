# Дизайн интерфейса — версия 0.3

## Что изменено

- `src/styles.css` — единая тёмная тема, цвета, панели, поля, кнопки, таблицы и адаптивная раскладка.
- `src/layouts/AppLayout.vue` — постоянная боковая навигация, верхняя панель и статус локального режима.
- `src/pages/HomePage.vue` — главный экран и карточки перехода в разделы.
- `src/components/common/PageIntro.vue` — единая шапка страниц; её можно повторно использовать в новых разделах.
- `src/components/gallery/MediaGalleryPage.vue` — вид панели импорта, фильтров, сетки и карточек файлов. Логика импорта сохранена.
- `src/pages/ArchiveGalleryPage.vue` — экран будущего каталога архивов.
- `src/pages/DatabasePage.vue` — таблица и инструменты поиска по демонстрационным записям.
- `src/pages/SettingsPage.vue` — расположение хранилища и визуализация структуры папок.

## Как поменять общий акцентный цвет

В начале `src/styles.css` найди переменную `--accent`. Сейчас это лаймовый цвет `#a3e635`. Можно заменить её на другой цвет, а затем при желании отдельно настроить `--accent-strong` и `--accent-text`.

## Что намеренно не менялось

`src/components/gallery/MediaViewer.vue` — компонент плеера видео и просмотрщика фото — оставлен без изменений. Также не менялись команды файловой системы, структура базы и логика маршрутизации.

## Проверка

Исходники проверены на парность основных тегов Vue. Полную сборку Vite/Vue выполнить не удалось: зависимости npm не были установлены из-за тайм-аута `npm install`. Перед использованием запусти `install.cmd`, а затем `check.cmd`.
