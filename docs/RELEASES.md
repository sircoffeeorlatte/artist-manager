# Релизы и обновления (будущий этап)

Автообновление не включено в MVP. Перед включением нужно:

1. Выбрать публичный канал релизов (например, Releases в репозитории).
2. Выпустить и хранить приватный ключ подписи безопасно вне проекта.
3. Настроить публичный ключ и endpoint обновлений в Tauri.
4. Публиковать подписанные артефакты и манифест обновления.
5. Добавить интерфейс «Проверить обновления» с возможностью отложить установку.
6. Проверить сценарий обновления на копии медиатеки и гарантировать, что пользовательские данные находятся вне каталога установки.
