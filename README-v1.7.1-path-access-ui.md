# Media Library v1.7.1 — Path Actions & UI Polish

Небольшой патч поверх Media Library v1.7. Распаковать поверх проекта с сохранением структуры папок.

## Что изменено

- `src/styles.css`: `.app-sidebar` больше не перекрывает drop overlay; overlay рендерится через `Teleport` в `body` и находится выше слоёв приложения. Улучшены карточки статуса в тёмном Liquid Glass, выравнивание кнопок путей и оформление импортера в стиле панелей настроек/базы файлов. Текст всей таблицы SQLite можно выделять.
- `src/services/fileLocations.ts`: общий сервис для открытия папки в системном файловом менеджере и открытия папки, содержащей конкретный файл.
- `src/pages/SettingsPage.vue`: блок «Текущее хранилище» перемещён под заголовок страницы; путь хранилища открывает папку. Путь `user-config.json` открывает содержащую его папку. Полный предварительный путь тоже кликабелен.
- `src/pages/DatabasePage.vue`: путь к SQLite открывает папку с базой данных; путь медиатеки открывает папку хранилища.
- `src/components/gallery/MediaViewer.vue`: в панели информации фото/видео добавлена кнопка «Открыть папку с файлом».
- `src/components/gallery/LibraryVideoPlayer.vue`: заменён отсутствующий private-use glyph для круговых индикаторов Video.js на CSS-кружки.
- `src/components/gallery/MediaGalleryPage.vue`: уточнена подсказка кнопки обновления.

## Важно про кнопку обновления галереи

Кнопка `.gallery-refresh-button` уже была подключена к реальной индексации: `reloadItems(true)` вызывает `mediaRepository.listByKind(..., true)`, сервис выполняет `refresh_media_index` (обновляет SQLite-индекс), после чего список снова читается из SQLite. Поэтому она запускает переиндексацию, а не только перерисовку интерфейса.

Открытие папок доступно только в приложении Tauri; в браузерном режиме кнопки отключены. Служба использует уже подключённый `@tauri-apps/plugin-opener`.

- Полный `npm run typecheck` в текущем окружении не запускается, потому что `node_modules` не установлены и команда `vue-tsc` отсутствует. Перед сборкой Windows нужно выполнить установку зависимостей и проверить `npm run typecheck` / `npm run tauri:build`.
